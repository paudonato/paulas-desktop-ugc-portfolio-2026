1. Extract this ZIP.
2. In your existing GitHub repository, replace `index.html`, `styles.css`, `script.js`, and `README.md` with these updated files.
3. Upload `assets/paula-portrait.jpg` into the `assets` folder (create it if missing).
4. Commit the changes. If connected to Vercel, it should redeploy automatically; otherwise redeploy from Vercel.
